DeepSeek Harness के कंपोज़र में `＋` के बगल में एक कैमरा बटन जोड़ता है, जिसमें दो विकल्प हैं:
**सीधा कैप्चर** (पूरी वर्चुअल स्क्रीन तुरंत) और **यह विंडो छिपाएँ** (पहले DSH विंडो छिपाएँ,
कैप्चर करें, फिर उसे **बिल्कुल पहले जैसा** बहाल करें — अगर वह मिनिमाइज़्ड थी तो भी)।

## Requirements

- DeepSeek Harness `0.1.7` या नया, डेस्कटॉप/वेब प्रोफ़ाइल।
- Windows: कैप्चर PowerShell + Win32 पर चलता है।
- Node `^22.19.0 || >=24.0.0`।
- **कोई रनटाइम निर्भरता नहीं**: होस्ट आधा केवल `node:*` मॉड्यूल आयात करता है।

## Install

```sh
dsh plugin --profile <profile> add ./dsh-shot              # स्रोत से
dsh plugin --profile <profile> add ./dsh-shot-0.1.0.tgz    # tarball से (pnpm pack)
```

ऐप को पुनः आरंभ करें: क्लाइंट बंडल का रिवीज़न शुरू होने पर तय होता है, इसलिए केवल पेज रीफ़्रेश
पर्याप्त नहीं है।

## Use

1. `＋` के बगल वाले कैमरा बटन पर क्लिक करें और दो में से एक विकल्प चुनें।
2. परत विंडो को ढकती है: क्षेत्र चुनने के लिए **एक आयत खींचें**।
3. चाहें तो एनोटेट करें और पुष्टि करें; छवि कंपोज़र ड्राफ़्ट में चली जाती है।

| क्रिया | परिणाम |
|---|---|
| **आठ हैंडल** खींचें (कोने और भुजा-मध्य) | उसी दिशा में आकार बदलें। |
| आयत के **भीतर** खींचें | आकार बदले बिना आयत हटाएँ। |
| कीबोर्ड के **तीर** | एक पिक्सेल सरकाएँ; **Shift** के साथ दस। |
| **राइट-क्लिक** / **पुनः चयन** | चयन हटाकर फिर से शुरू करें। |
| **Esc** / राइट-क्लिक | एक स्तर पीछे (एनोटेशन अनडू → पुनः चयन → बाहर)। |

उपकरण: **आयत**, **तीर**, **टेक्स्ट** (किसी बिंदु पर क्लिक करें, लिखें और **Enter** दबाएँ;
**Esc** रद्द करता है; **डबल-क्लिक** से मौजूदा टेक्स्ट संपादित होता है), **आठ रंगों** का पैलेट,
**अनडू** और **पुनः चयन**। टेक्स्ट पर पारभासी गहरी पट्टी रहती है ताकि किसी भी पृष्ठभूमि पर
पढ़ा जा सके।

## How it fits together

| आधा | फ़ाइल | कहाँ चलता है |
|---|---|---|
| होस्ट | `lib/index.js` | DSH सर्वर; `/api/dsh-shot/*` रूट पंजीकृत करता है और `scripts/capture.ps1` चलाता है। |
| क्लाइंट | `lib/client.js` | ब्राउज़र; कंपोज़र बटन और चयन/एनोटेशन परत। |
| कैप्चर | `scripts/capture.ps1` | अलग PowerShell प्रक्रिया; DSH विंडो ढूँढती है, छिपाती/बहाल करती है और वर्चुअल स्क्रीन कैप्चर करती है। |

क्लाइंट आधा `package.json` में `dsh.client` के अंतर्गत घोषित है और
`/plugins/dsh-shot/client.js` से परोसा जाता है।

## Known limitations

- **केवल Windows**: कैप्चर PowerShell + Win32 पर आधारित है।
- परत **विंडो** को ढकती है, स्क्रीन को नहीं: कैप्चर को विंडो भरने के लिए स्केल किया जाता है,
  इसलिए जो अनुपात में नहीं बैठता वह कट जाता है। कई मॉनिटर एक ही वर्चुअल स्क्रीन माने जाते हैं और
  छोटी विंडो उसके सभी कोनों तक नहीं पहुँच सकती।
- छिपाने का मोड DSH को लगभग 0.3–1.2 सेकंड के लिए गायब कर देता है।
- कभी-कभी कैप्चर स्क्रिप्ट लगभग खाली फ़्रेम लौटाती है; दोबारा कैप्चर करने पर ठीक हो जाता है।

